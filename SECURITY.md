# Security Policy

## Supported versions

Security fixes are applied to the latest release and the current `main` branch.

## Reporting a vulnerability

Please do not open a public issue for vulnerabilities involving account data, authentication files, local encryption or update packages.

Report the problem privately through GitHub's security-advisory flow when available, or use the contact method listed on the repository owner's GitHub profile. Include:

- affected version or commit
- reproduction steps
- expected and observed behaviour
- potential impact
- a minimal proof of concept, without real credentials or account data

You should receive an acknowledgement within seven days. Please allow time for investigation and a coordinated fix before publishing details.

## Scope

This policy covers Codex Simple Accounts itself. Vulnerabilities in Codex Desktop, ChatGPT, Windows or third-party dependencies should also be reported to their respective maintainers.
